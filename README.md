## Shakespeare-Lernplattform (Englisch Q2)

Im Ordner [`shakespeare-q2/`](shakespeare-q2/index.html) liegt eine Lernplattform für die Shakespeare-Analyse in der Q2.
Einfach `shakespeare-q2/index.html` im Browser öffnen, es wird nichts installiert.

Inhalte:
- Kontext: Shakespeares Leben, das Elisabethanische Zeitalter, das Globe Theatre, Gattungen
- Dramenstruktur: interaktive Freytag-Pyramide, Tragödie/Komödie, dramatische Mittel
- Vers & Sprache: Blank verse, Prosa, Reim, Metrum-Trainer, Sonnet 18, Early Modern English
- Stilmittel: durchsuchbares Glossar mit Beispielen und Wirkung
- Stücke: Romeo and Juliet, Macbeth, Hamlet, Othello, A Midsummer Night's Dream, The Merchant of Venice, Julius Caesar
- Analyse-Schemas: Szene, Soliloquy, Charakterisierung, Sonett, Filmszene, Kommentar, kreative Aufgaben; Operatoren, Formulierungshilfen, Zitierregeln
- Filmanalyse, Karteikarten, Quiz und Klausur-Checkliste

Der Lernstand (Karteikarten, Quiz, Checkliste) wird lokal im Browser gespeichert.
